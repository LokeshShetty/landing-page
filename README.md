# Agent Sprawl Score landing page

The campaign landing page: a 3D field of agents you can take control of, a five-tap Agent Sprawl Score, an agent registry that flips to owned, and an Agent Test Drive console. Concept page for Lyzr Opencontroller, not an official Lyzr page.

Open `index.html` in any browser. No build step, no dependencies, nothing is sent anywhere.
